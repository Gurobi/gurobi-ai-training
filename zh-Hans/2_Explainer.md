# 2. 使用 Gurobi Explainer 诊断模型

在上一份文档（`1_Modeler` **附录**）中，你为一家乳品厂构建了生产计划模型，并得到了可行的最优解。
在本文档中，这个模型出了问题；你将使用 **Explainer** 诊断原因、计算需要松弛多少，并分析在哪里投资
最能提升利润。

> ⚠️ 本文档同样没有需要运行的代码。所有诊断工作都在
> **[intelligence.gurobi.com](https://intelligence.gurobi.com)** 上的 **Explainer** 中完成。
> 本文档提供场景说明、分步指南，以及可用来核对结果的预期结果。

## 什么是 Explainer？

**Explainer**（Experimental）是一个智能体：它接收你上传的现有模型实例，在其上运行 Gurobi 的诊断工具，
并用业务语言解释诊断结果。Intelligence Hub 提供三种工作流。

| 工作流 | 示例问题 | 使用的诊断工具 |
|---|---|---|
| **不可行性诊断**（Infeasibility Diagnosis） | 我的模型为什么不可行？ | `computeIIS()` |
| **可行性修复**（Feasibility Restoration） | 应该松弛哪些约束？松弛多少？ | `feasRelax()` |
| **灵敏度分析**（Sensitivity Analysis） | 哪些约束/产能对目标函数影响最大？ | 影子价格（`Pi`）、`SARHS` |

> 💡 Explainer 不会把模型和求解器当作“黑箱”——它会把输入（模型文件）与输出（诊断结果）真正对应起来
> 进行解释。正如你在上一个实验（`1_Modeler`）中用验收测试核验结果一样，请在操作过程中亲自确认
> Explainer 的解释与实际数值是否一致。

## 第 1 部分　不可行性诊断——为什么不可行？（Q1）

### 步骤

1. 打开 Explainer，选择 **Infeasibility Diagnosis**（不可行性诊断）选项卡。
2. 上传 `moodel.lp`。
3. 示例问题：*“告诉我这个模型为什么不可行。”*
4. 查看 Explainer 报告的 **IIS**（不可约不一致子系统，Irreducible Inconsistent Subset——一组相互冲突、
   且无法再进一步缩减的最小约束与界限集合）。

### 任务

根据 Explainer 的回答，列出可能导致不可行的候选约束/界限，并说明每一项为何会造成问题。与原版挑战赛
一样，厂长（即你的讲师）只允许调整其中**一项**候选——**刚刚新增的那项要求**。你能猜出是哪一个约束吗？

### 预期结果

- IIS 中的约束：**19** 个
- IIS 中的界限：**9** 个（8 个下界，1 个上界）
- 不可行的根本原因：

  新增的 `Minimum_Premium` 约束（高端产品最低产量 20,000 桶）与高端乳饮料的质量标准（质量指数 ≥ 94）
  正面冲突。要达到 94，需要大量高品质原料——蛋白浓缩物（质量 115）和发酵浓缩物（质量 105）——但二者
  分别受**蛋白浓缩设备**（10,000 桶/天）和**二次加工设备**（8,000 桶/天）的产能限制。即使两台设备
  都满负荷运行，也无法生产足够的高品质原料，让全部 20,000 桶都达到质量标准，因此模型变得不可行。

  → 物理产能（分离、蛋白浓缩、二次加工）和质量标准（84、94）反映的是工厂的实际设备和合同条款，
  无法更改。而 `Minimum_Premium` 是市场部刚刚加入的目标，因此它最有可能是厂长允许你调整的那一项。

遇到困难时再展开。以下是通过 API 原样上传 `moodel.lp` 并提出相同问题后得到的实际回答。）

<details>
<summary>查看回答示例</summary>

> **你**：告诉我这个模型为什么不可行。

Explainer 运行 `computeIIS()`，并将 IIS 中的约束和界限按如下方式分组。

| 分组 | 包含的约束/界限 | 说明 |
|---|---|---|
| 最低产量要求 | `Minimum_Premium` | 要求 Premium_drink 至少生产 20,000 单位 |
| 质量要求 | `Quality_tol_premium_drink`（另有 1 项） | 要求 Premium_drink 质量指数 ≥ 94 → 需要足够的高品质中间产品（蛋白浓缩物、发酵浓缩物） |
| 工艺产能限制 | `Protein_conc_cap`（≤ 10,000）、`Secondary_proc_cap`（≤ 8,000） | 生产上述高品质中间产品的两台设备的加工上限 |
| 原料投入上限 + 物料流平衡 | `milk_in[2]`（UB = 30,000）以及分离/调配平衡等式 | 上游生乳供应本身决定了中间产品产量的上限 |

> 简而言之：“要生产 20,000 单位高品质（94 以上）的 Premium_drink，需要足够的高品质中间产品，
> 但设备产能限制和生乳投入上限使这一点无法实现。”

随后，Explainer 按优先级给出松弛方案。

1. **提高工艺产能上限**——提高 `Protein_conc_cap` 和 `Secondary_proc_cap` 的 RHS（扩建设备）
2. **提高生乳投入上限**——提高 `milk_in[2]` 的 UB
3. **放宽最低产量/质量标准**——调整 `Minimum_Premium` 或 `Quality_tol_premium_drink`

</details>

## 第 2 部分　可行性修复——最小松弛量是多少？（Q2）

![团队围在笔记本电脑前：“既然知道可以松弛‘什么’了，来看看该松弛‘多少’……”工程师指着显示“可行性松弛计算中……”的屏幕说：“好吧，就依你们——找出‘应急规格’。”最后大家看着结果：“好吧，这已经是我们能做到的最好结果了……”——不得不认真算清这笔账。](../assets/zh-Hans/explainer_q2_restoration.jpg)

原因找到了，但“干脆当这项要求不存在”并不是答案。市场部和厂长都不打算完全放弃它。所以下一个问题是：
“需要削减多少？”

### 步骤

1. 在 Explainer 中选择 **Feasibility Restoration**（可行性修复）选项卡，上传同一个 `moodel.lp`。
2. 厂长表示：“只有刚刚新增的高端产品最低产量要求可以调整。其他物理产能和质量标准没有商量余地。”
3. 示例问题：*“如果只松弛高端产品最低产量要求，需要削减多少才能让模型可行？”*
4. 查看 Explainer 基于 `feasRelax` 的回答。Explainer 会在回答中附上**松弛后的模型文件**
   （例如 `moodel_repaired.lp`）——请下载下来，第 3 部分还会用到。

### 预期结果（利润单位：百美元 (USD 100)）

- 最小松弛量（桶）：**≈ 990.76**
- 松弛后的高端产品最低产量（桶）：**≈ 19,009.24**（20,000 → 19,009.24）
- 总利润：**185,746.56**

| 产品 | 产量 | 总利润 |
|---|---|---|
| 高端乳饮料 | 19,009.24 | 133,064.69 |
| 标准乳饮料（Standard Dairy Drink） | 0.00 | 0.00 |
| 烹饪奶油（Cooking Cream） | 12,982.97 | 51,931.86 |
| 乳基料（Dairy Base Mix） | 0.00 | 0.00 |
| 黄油固形物（Butter Solids） | 500.00 | 750.00 |

> ※ Explainer 显示的小数位数或措辞可能有所不同，但关键数值（松弛量 ≈ 990.8 桶，总利润 ≈ 185,746.6）
> 必须与上面一致。利润低于 `1_Modeler`（211,365.13），是因为为了满足高端乳饮料的要求，原本可用于
> 其他高利润产品（如标准乳饮料）的原料被挪走了。

## 第 3 部分　灵敏度分析——应该投资哪里？（Q3）

![团队欢呼：“成功了！模型可行了！”屏幕上显示“优化器状态：可行 ✓”。瑞原乳业的 CFO 大笑着称赞：“哈！我的英雄们！”“干得好——问题解决了！你们力挽狂澜，让运奶卡车继续跑起来了！”随后他靠在椅背上问道：“不过现在告诉我：我们该投资哪里，才能赚更多的钱？”团队：“不是吧？”](../assets/zh-Hans/explainer_q3_investment.jpg)

问题并没有就此结束。工厂恢复了运转，但 CFO 紧接着追问——
*“不过现在告诉我：我们该投资哪里，才能赚更多的钱？”*

### 步骤

1. 在 Explainer 中选择 **Sensitivity Analysis**（灵敏度分析）选项卡，上传第 2 部分中修复（松弛）后的
   模型。（如果第 2 部分没有拿到文件，请改用 [`models/moodel_repaired.lp`](../models/moodel_repaired.lp)。）
2. 示例问题：*“扩建哪台设备的产能最能提升利润？能提升多少？最多可以扩建到多少？”*
3. 查看以下三个产能约束的**影子价格**和**有效范围**：
   - 最大分离产能：45,000 桶/天
   - 蛋白浓缩产能：10,000 桶/天
   - 二次加工产能：8,000 桶/天

### 预期结果

| 设备 | 影子价格（百美元 / 桶·天） | 有效范围（上限） |
|---|---|---|
| 分离产能 | 0.00（非紧约束） | 不适用 |
| 蛋白浓缩产能 | **74.50** | 最高约 10,301 桶/天（+301 桶） |
| 二次加工产能 | **16.35** | 最高约 9,444 桶/天（+1,444 桶） |

**投资优先级**：优先扩建**蛋白浓缩设备**。其每桶边际利润（74.50）约为二次加工设备（16.35）的
**4.6 倍**，投资回报最高。但请注意，该影子价格仅在当前最优基保持不变时（最多 +301 桶/天）成立；
超出这一范围的扩建需要重新进行灵敏度分析。分离产能已有富余（影子价格为 0），因此不是投资重点。
